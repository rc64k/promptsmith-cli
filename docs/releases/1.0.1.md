# PromptSmith-cli 1.0.1

Patch release focused on cross-platform compatibility and stability.

## What's fixed

- Improved SQLite connection cleanup to prevent lingering database
  handles, particularly on Windows.
- Standardized UTF-8 file handling across operating systems.
- Stabilized the profile editor integration test.
- Corrected cross-platform documentation.

## Compatibility

- Python 3.11 through 3.14.
- CI validated on macOS, Linux, and Windows.
- Portable builds provided for:
  - macOS Apple Silicon
  - macOS Intel
  - Linux x64
  - Windows x64

## Known limitations

- Portable builds remain unsigned and unnotarized.
- macOS Gatekeeper and Windows SmartScreen may warn on first launch.
